## فحوص على الناتج المعروض
تُجرى على المخرَج بعد عرضه أو تصويره، لا على الشيفرة وحدها.

| الفحص | المعيار |
|---|---|
| التباين | نص المتن 4.5:1 على الأقل، والنص الكبير 3:1. النص الثانوي على خلفية ملونة يُشتق من لون الخلفية، لا رماديًا |
| العمق | الظل له إزاحة وتمويه ناعم. الهالة الملونة بلا إزاحة زخرفة لا عمق |
| المسافات | تقارب داخل المجموعة الواحدة، وفصل واضح بين المجموعات، ومسافة فوق العنوان أكبر من التي تحته |
| الطباعة | سطر المتن بين 65 و75 حرفًا تقريبًا، وتدرج واضح في الحجم والوزن، ولا نص يخرج عن إطاره في أي مقاس |
| الحركة | لحظة حركة واحدة مقصودة إن وُجدت، لا تأثير متكرر على كل قسم |
| الحالات | في الواجهات: التمرير، والتعطيل، والتحميل، والخطأ، والحالة الفارغة، والتركيز بلوحة المفاتيح |
| النصوص | أسماء الأزرار تصف الإجراء، ورسائل الخطأ تذكر المشكلة وطريقة معالجتها |
| التغطية | كل متطلبات الطلب ظاهرة ويمكن العثور عليها خلال ثوانٍ |
| RTL | الأرقام في الجداول متسقة، والأيقونات الاتجاهية معكوسة، وترتيب القراءة من اليمين في كل عنصر |

## عادات تُتجنب
ليست محظورة إذا طلبها المستخدم صراحة. لكن اللجوء إليها دون قرار يعني أن التصميم لم يُحسم.

| العادة | البديل |
|---|---|
| بطاقات متساوية من أيقونة وعنوان ونص هيكلًا للصفحة كلها، أو بطاقات داخل بطاقات | تنويع البنية بحسب المحتوى: نثر، أو جدول، أو مخطط |
| قالب "الرقم الكبير": رقم ضخم وتسمية صغيرة وإحصاءات جانبية | عرض الرقم في سياقه مع مصدره ودلالته |
| تسمية صغيرة فوق كل عنوان | حذفها؛ العنوان يحمل وزنه بنفسه |
| ترقيم الأقسام (01، 02، 03) | يُستخدم فقط إذا كان التسلسل نفسه معلومة يحتاجها القارئ |
| نص بتدرج لوني | التأكيد بالوزن أو الحجم |
| الزجاج والتمويه زخرفةً | استخدامهما فقط لتأثير محدد مقصود |
| حد ملون سميك على جانب البطاقات والتنبيهات | حد رفيع، أو خلفية خفيفة، أو لا شيء |
| مخططات مصغرة وحلقات تقدم بدل المحتوى الفعلي | المحتوى نفسه، أو رسم بياني حقيقي ببيانات حقيقية |
| رموز Unicode أو رموز تعبيرية بدل الأيقونات | مكتبة أيقونات واحدة بسماكة خط موحدة |
| خط النظام الافتراضي خطًا رئيسيًا | خط يناسب الهوية ويدعم العربية جيدًا |
| خلفيات مخططة أو شبكية بلا مبرر | سطح نظيف؛ النقش فقط من عالم الموضوع نفسه |
| قيم وأرقام توضيحية تُعرض كأنها حقيقية | كل رقم من مصدر، والقيم التوضيحية موسومة بأنها كذلك |
